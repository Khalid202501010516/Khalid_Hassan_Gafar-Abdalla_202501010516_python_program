# Week 10 Salary Calculator

This Python program calculates an employee's monthly salary.

## Features

- Collects employee information
- Calculates overtime at RM25 per hour
- Gives a RM500 reward to employees who worked for more than 3 years
- Calculates gross salary
- Calculates EPF deduction at 11%
- Calculates SOCSO deduction at 0.5%
- Calculates net salary
- Displays a salary report

## Project Files

- `main.py` - Coordinates the program
- `employee.py` - Collects employee information
- `salary.py` - Performs salary calculations
- `report.py` - Displays the salary report

## Run the Program

```bash
python main.py
