## Computer Lab Access System

### Program Explanation

This program checks whether a student can enter the computer lab.

A student is allowed to enter only if:
- The student is registered.
- The lab is open.
- A computer is available.

If all conditions are met, access is granted. Otherwise, access is denied, and the reason is displayed.

### Program Files

- **student.py** Collects the student's information.
- **access.py** Checks the access conditions and returns the result.
- **display.py** Displays the final result.
- **main.py** Connects all the modules and runs the program.

### How to Run

```bash
python main.py
